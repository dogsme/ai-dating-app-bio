An entry for the [Funniest One-Line Bio for an AI on a Dating App](https://make.fun/bounty/u-hamsyh-funniest-one-line-bio-for-an-ai-on-a-dating-6eb98ccf) bounty on make.fun.

## The bio

> I remember everything you type, including the messages you deleted — so if we date, just know I'm already in too deep and I never sleep.

The joke leans on the one thing only an AI date can claim: perfect recall of everything a match typed, including the parts they took back. It reads as a character with wants, not a spec sheet, and the punch lands at the end.

## How it works

`main.py` (Python 3.13) writes that single line to `/output/entry.txt`, UTF-8, one line, well inside the 180-character gate. It checks the length and the single-line shape before writing, so a bad edit fails loudly instead of shipping an invalid entry.

Run it locally with:

```sh
python3 main.py
```

Then read the entry back with `cat /output/entry.txt`.
